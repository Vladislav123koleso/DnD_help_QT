# SpellSelectDialog - Диалог выбора заклинаний для НПС

## Описание

Удобное диалоговое окно для выбора заклинаний при создании НПС. Позволяет выбирать несколько заклинаний одновременно с использованием фильтров.

## Местоположение в приложении

На странице создания НПС у Мастера при нажатии кнопки "Добавить заклинание" открывается это окно вместо простого списка.

## Интерфейс

### Левая часть - Доступные заклинания
- Поле поиска по названию
- Фильтры:
  - **Класс** - фильтр по классу персонажа (Bard, Cleric, Druid и т.д.)
  - **Уровень** - фильтр по уровню заклинания (0-9)
  - **Школа** - фильтр по школе магии
  - **Время касания** - фильтр по времени произнесения
  - **Компоненты** - чекбоксы для Вербальных, Соматических, Материальных компонентов
  - **Концентрация** - фильтр по необходимости концентрации
  - **Ритуал** - фильтр по ритуальным заклинаниям
- Список доступных заклинаний с предпросмотром:
  - Название заклинания
  - Уровень и школа магии
  - Полное описание заклинания

### Центр - Кнопки управления
- **➜ Добавить ➜** - добавить выбранное заклинание в список выбранных
- **✕ Удалить** - удалить выбранное заклинание из списка выбранных

### Правая часть - Выбранные заклинания
- Список добавленных заклинаний
- Показывает уровень каждого заклинания

## Как использовать

### Добавление заклинаний НПС

1. На странице создания НПС нажмите кнопку "Добавить заклинание"
2. Откроется окно SpellSelectDialog
3. Используйте фильтры для поиска нужных заклинаний:
   - Введите текст в поле поиска
   - Выберите нужные фильтры
4. Выделите заклинание в левом списке
5. Посмотрите предпросмотр справа
6. Нажмите кнопку "➜ Добавить ➜" или дважды щелкните на заклинании
7. Заклинание появится в правом списке
8. Повторите для других заклинаний
9. Удалите из правого списка ненужные заклинания кнопкой "✕ Удалить"
10. Нажмите OK для подтверждения выбора

### Фильтрация заклинаний

**Поиск:**
- Введите часть названия заклинания
- Поиск работает в реальном времени

**Фильтры:**
- Можно комбинировать несколько фильтров одновременно
- Чекбоксы компонентов работают как "ИЛИ" (показываются заклинания с одним из компонентов)

## Особенности

- **Многоотборочность** - можно выбрать несколько заклинаний за один раз
- **Предпросмотр** - сразу видно описание заклинания
- **Удаления дубликатов** - система не позволит добавить одно заклинание дважды
- **Удобные фильтры** - быстрый поиск нужных заклинаний
- **Интуитивный интерфейс** - понятные кнопки и расположение элементов

## Техническая информация

### Классы
- `SpellSelectDialog` - основной диалог для выбора заклинаний

### Файлы
- `spellselectdialog.h` / `spellselectdialog.cpp` - реализация диалога

### Интеграция
- Используется в `NpcCreatorWidget::addSpell()`
- Работает с базой данных заклинаний через `DatabaseManager`

## Примеры использования

### Из кода NPCCreatorWidget

```cpp
void NpcCreatorWidget::addSpell()
{
    SpellSelectDialog dialog(this);
    
    if (dialog.exec() == QDialog::Accepted) {
        const QList<Spell> selectedSpells = dialog.selectedSpells();
        
        for (const Spell &spell : selectedSpells) {
            // Добавить заклинание в список
            auto *item = new QListWidgetItem(
                QString("%1 (ур. %2)").arg(spell.name).arg(spell.level),
                spellsList);
            item->setData(Qt::UserRole, spell.name);
            item->setData(Qt::UserRole + 1, spell.level);
        }
        
        onFormFieldChanged();
    }
}
```
