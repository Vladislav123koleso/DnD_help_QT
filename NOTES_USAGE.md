# Функциональность Заметок в D&D Helper

## Описание

Модуль заметок позволяет игрокам и мастерам вести собственные заметки по кампании. Заметки хранят форматированный текст с поддержкой:
- Жирный шрифт (Ж)
- Курсив (К)
- Подчеркивание (П)
- Различные шрифты
- Размер шрифта (8-72 пт)
- Цвет текста
- Цвет выделения текста

## Местоположение в приложении

### Для Игрока (Player)
- Вкладка "Заметки" в главном интерфейсе
- Расположена первой в списке вкладок

### Для Мастера (Master)
- Пункт "Заметки" в левом меню
- Первый пункт в списке

## Интерфейс

### Левая Панель
- **Список заметок** - показывает все созданные заметки с датой последнего изменения
- **+ Новая заметка** - кнопка для создания новой заметки
- **- Удалить** - кнопка для удаления выбранной заметки

### Верхняя Панель Инструментов
Содержит кнопки форматирования:
- **Ж** - Жирный текст (Ctrl+B)
- **К** - Курсив (Ctrl+I)
- **П** - Подчеркивание (Ctrl+U)
- **Выбор шрифта** - выпадающий список шрифтов
- **Размер** - спинбокс для выбора размера (8-72 пт)
- **A** - Цвет текста
- **◼** - Цвет выделения текста

### Основная Зона Редактора
- Редактор с поддержкой форматированного текста (Rich Text)
- Автоматическое сохранение при переключении между заметками

## Как Использовать

### Создание Новой Заметки
1. Нажмите кнопку **"+ Новая заметка"**
2. Введите название заметки в диалоговом окне
3. Нажмите OK

### Редактирование Заметки
1. Выберите заметку из списка слева
2. Редактируйте текст в основной области
3. Используйте кнопки форматирования для изменения стиля

### Форматирование Текста
1. Выделите текст в редакторе
2. Нажмите соответствующую кнопку форматирования:
   - **Жирный** - нажмите кнопку "Ж"
   - **Курсив** - нажмите кнопку "К"
   - **Подчеркивание** - нажмите кнопку "П"

### Изменение Шрифта
1. Выделите текст
2. Выберите шрифт из выпадающего списка

### Изменение Размера Шрифта
1. Выделите текст
2. Установите нужный размер в спинбоксе (8-72 пт)

### Изменение Цвета Текста
1. Выделите текст
2. Нажмите кнопку "A" (Цвет текста)
3. Выберите цвет в диалоговом окне выбора цвета

### Изменение Цвета Выделения
1. Выделите текст
2. Нажмите кнопку "◼" (Цвет выделения)
3. Выберите цвет в диалоговом окне выбора цвета

### Удаление Заметки
1. Выберите заметку в списке
2. Нажмите кнопку **"- Удалить"**
3. Подтвердите удаление в диалоговом окне

## Особенности

- **Автосохранение** - заметки автоматически сохраняются при переключении между ними
- **Отметки времени** - каждая заметка имеет информацию о времени создания и последнего изменения
- **Уникальные ID** - каждая заметка получает уникальный идентификатор
- **Форматированный текст** - поддержка HTML для сохранения всего форматирования

## Техническая Информация

### Классы
- `Note` - модель для хранения данных заметки
- `NotesWidget` - основной виджет для управления заметками

### Файлы
- `note.h` / `note.cpp` - классы для работы с заметками
- `noteswidget.h` / `noteswidget.cpp` - UI для редактора заметок

### Интеграция
- PlayerPage содержит NotesWidget как первую вкладку
- MasterPage содержит NotesWidget как первый пункт меню
